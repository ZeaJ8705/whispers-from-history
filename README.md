# Whispers from History

**A responsive historical exploration website and front-end development portfolio project.**

## About the Project

Whispers from History is a multipage website exploring historical buildings and artifacts associated with their stories.

The website features six historical buildings and six corresponding artifacts. Visitors can explore the collections, read about individual locations and objects, and navigate between related building and artifact pages.

The project was developed to practice front-end web development through the creation of a complete, interconnected website.

## Technologies Used

- **HTML5:** Semantic page structure, navigation, image elements, and accessibility features.
- **CSS3:** Responsive layouts, CSS Grid, Flexbox, custom properties, media queries, and interactive styling.
- **JavaScript:** DOM manipulation, event listeners, text filtering, conditional logic, and dynamic search results.
- **Git and GitHub:** Version control and project management.
- **Visual Studio Code:** Development environment.
- **Google Fonts:** Cinzel Decorative and Berkshire Swash.

## Website Features

- Responsive layouts for mobile, tablet, and desktop.
- Historical Buildings collection with six individual pages.
- Historical Artifacts collection with six individual pages.
- Direct navigation between related buildings and artifacts.
- Live JavaScript search filters on both collection pages.
- Dynamic feedback when a search produces no matches.
- Accessible navigation, image descriptions, and keyboard focus styling.
- Consistent visual design using cream, burgundy, and antique brass.

## Project Structure

- `Website/index.html` — Homepage
- `Website/historical-buildings/` — Buildings collection and individual pages
- `Website/historical-artifacts/` — Artifacts collection and individual pages
- `Website/images/` — Local image assets
- `Website/styles.css` — Shared stylesheet
- `Website/script.js` — JavaScript functionality
- `DEVLOG.md` — Development progress and learning record

## Running the Website Locally

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Open `Website/index.html` in your browser, or use the Live Server extension.
4. Explore the collections and their individual pages.

## Development and Learning

This project provided hands-on experience creating and maintaining a multipage website.

Key areas of learning included responsive design, semantic HTML, reusable CSS, relative file paths, JavaScript interactions, debugging with Chrome Developer Tools, and independently troubleshooting code.

The website was also used to practice organizing and completing a development project with Git and GitHub.

## Historical Content and Images

Historical descriptions were developed with AI assistance and historical references. Original historical photographs are credited where applicable. Some artifact images are AI-generated interpretive illustrations rather than photographs of original objects.

Image sources and credits are provided on their corresponding pages.
